## 🎯 Objetivos del Módulo

Al completar estos ejercicios, serás capaz de:

- ✅ Configurar un entorno de desarrollo TypeScript moderno
- ✅ Escribir y ejecutar programas TypeScript básicos
- ✅ Entender las diferencias entre TypeScript y JavaScript
- ✅ Configurar y personalizar el compilador TypeScript
- ✅ Utilizar herramientas de desarrollo como Bun y Biome

---

## 🚀 Cómo Empezar

1. **Asegúrate de tener instalado:**
   - Node.js 18+ o Bun
   - Visual Studio Code
   - Git

2. **Completa los ejercicios en orden:**
   - Cada ejercicio construye sobre los anteriores
   - Lee cuidadosamente los requisitos
   - Implementa tu solución paso a paso

3. **Verifica tu progreso:**
   - Ejecuta los comandos de verificación
   - Compara con las soluciones oficiales
   - Contribuye con tu propia solución

## 📊 Resumen de Ejercicios

### 🔧 [Ejercicio 1: Configuración del Entorno](./01-Configuración_Entorno.md)

**Objetivo:** Configurar un workspace TypeScript completo con herramientas modernas

**Conceptos:** Instalación, configuración, setup inicial

### 🚀 [Ejercicio 2: Primer Programa TypeScript](./02-Primer_Programa.md)

**Objetivo:** Crear tu primer programa TypeScript funcional

**Conceptos:** Sintaxis básica, tipos implícitos, compilación

### 🔍 [Ejercicio 3: Tipos Básicos vs JavaScript](./03-Tipos_Básicos_vs_JS.md)

**Objetivo:** Comprender las ventajas del sistema de tipos de TypeScript

**Conceptos:** Type safety, inferencia, errores en tiempo de compilación

### ⚙️ [Ejercicio 4: Compilación y Ejecución](./04-Compilación_Ejecución.md)

**Objetivo:** Dominar el workflow de desarrollo con TypeScript

**Conceptos:** Compilación, watch mode, scripts de npm/bun
