## 🚀 Cómo Usar

1. **Selecciona el módulo** que estás estudiando
2. **Lee el caso de ejercicio** completo
3. **Implementa tu solución** en TypeScript
4. **Compara** con las soluciones en `/Solutions/`
5. **Contribuye** con tu propia solución via PR

## 📝 Formato de Ejercicios

Cada ejercicio incluye:

- ✅ **Descripción clara** del problema
- ✅ **Requisitos específicos** a cumplir
- ✅ **Ejemplos de entrada/salida**
- ✅ **Pistas y conceptos clave**
- ✅ **Criterios de evaluación**
