# 📖 Módulo 2: Tipos Básicos y Fundamentales

> **Duración:** 12 horas | **Estado:** 🔄 En Progreso

## 🎯 Objetivos del Módulo

Al finalizar este módulo, serás capaz de:

- ✅ Dominar el sistema de tipos de TypeScript
- ✅ Trabajar con tipos primitivos y compuestos
- ✅ Utilizar la inferencia de tipos de forma efectiva
- ✅ Implementar literal types y enums
- ✅ Aplicar type assertions y narrowing
- ✅ Crear tipos seguros y robustos

---

## 📚 Contenido del Módulo

### 🔧 [2.1 Sistema de Tipos de TypeScript](./01-sistema-tipos.md)

**Duración:** 4 horas

Comprende el sistema de tipos de TypeScript y cómo trabajar con tipos primitivos y compuestos básicos.

#### 🎯 [2.1.1 Tipos Primitivos](./01-1-tipos-primitivos.md)

**Duración:** 2 horas

- Tipos básicos: string, number, boolean
- Tipos especiales: bigint y symbol
- Valores especiales: null y undefined
- Tipos únicos: void y never
- Tipos de escape: unknown y any

#### 🔧 [2.1.2 Tipos Compuestos Básicos](./01-2-tipos-compuestos.md)

**Duración:** 2 horas

- Arrays y tuplas
- Objetos e interfaces básicas
- Funciones y sus tipos
- Union types (|) y uso práctico
- Intersection types (&) y combinaciones

---

### 🧠 [2.2 Inferencia de Tipos](./02-inferencia-tipos.md)

**Duración:** 3 horas

Aprende cómo TypeScript infiere tipos automáticamente y cuándo es necesario especificarlos explícitamente.

**Temas cubiertos:**

- Mecanismo de inferencia de TypeScript
- Casos donde la inferencia es suficiente
- Cuándo especificar tipos explícitamente
- Best practices para aprovechar la inferencia
- Casos límite y consideraciones especiales

---

### 📝 [2.3 Literales y Enums](./03-literales-enums.md)

**Duración:** 3 horas

Domina los literal types y enums para crear tipos más específicos y expresivos.

#### 🎨 [2.3.1 Literal Types](./03-1-literal-types.md)

**Duración:** 1.5 horas

- String literals y casos de uso
- Number literals y aplicaciones
- Boolean literals y ventajas
- Template literal types (TypeScript 4.1+)

#### 🔢 [2.3.2 Enums](./03-2-enums.md)

**Duración:** 1.5 horas

- Numeric enums y comportamiento
- String enums y legibilidad
- Const enums y optimización
- Cuándo usar enums vs union types

---

### 🎯 [2.4 Type Assertions y Narrowing](./04-assertions-narrowing.md)

**Duración:** 2 horas

Aprende técnicas avanzadas para trabajar con tipos dinámicos y realizar conversiones seguras.

**Temas cubiertos:**

- Type assertions con 'as' y casos de uso
- Type guards básicos y implementación
- Operadores typeof e instanceof
- Discriminated unions y pattern matching
- Narrowing automático y manual
